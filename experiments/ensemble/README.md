# 앙상블 모델 — 시간별 SMP 예측·80% 범위·급락/급등 경보

> **최신은 v2(2026-11-02)** 입니다. 구성·비율·성적·재현 순서는 **[RECIPE.md](RECIPE.md)** 를 보세요.
> v2에서 바뀐 점: LightGBM 보정형(미세조정 Chronos 입력) 추가, 공공데이터 API로 2026-10-03~11-02를 보충한 새 시험 구간, 결과표 판정 열.
> 아래는 v1(2026-10-26) 기록이며, 2~5장의 성적·비율 숫자는 v1 기준입니다.

중간 피드백(2026. 10. 21.) 반영: 「LightGBM 기본, Chronos·LSTM 비교 → 최종은 앙상블」, 「주의 / 경보 2단계」, 「15시(근사)·21시(확정) 2단 운용」, 「급등도 함께 보기」.

- 개발 구간 2024~2025: 모델 선택, 가중치, 보정 계수, 경보 기준을 모두 여기서 정했다.
- 시험 구간 2026-01-01~10-02: 결정을 마친 뒤 1회만 평가했다. 시험 결과를 보고 아무것도 다시 조정하지 않았다.
- 모든 모델은 그 시점 이전 자료로만 다시 학습한다(LightGBM은 매주, LSTM은 분기마다, Chronos 미세조정은 매년, 경보 모델은 매달). D일 저녁에 알 수 없는 정보(당일 기상 실측 등)는 쓰지 않는다.
- 지표는 `scripts/step8_rmae.py`와 같다. rMAE는 MAE를 전일 동시간 기준선(naive-1)의 MAE로 나눈 값이고, MAPE와 편의의 분모는 max(실적, 20)이다.

## 1. 어떤 분석에 어떤 모델을 어떤 비율로

| 분석 | 최종 구성과 비율 | 비율 정하는 법 |
|---|---|---|
| **시간별 가격 D+1 (21시)** | Chronos-2 LoRA 미세조정 **44%** · LightGBM 적층(Chronos 분위수를 변수로, 매주 재학습) **38%** · LightGBM-L1(매주 재학습) **18%** — 개발 구간 평균. 2026년 평균은 52% · 31% · 17% | 매달 1일, 직전 180일 표본 외 예측으로 MAE 최소 가중(음수 없음·합 1, 선형계획) |
| **80% 예측 범위** | 결합 예측 + 최근 91일 잔차의 10%·90% 분위수. 시간대별 폭은 Chronos-2 분위수 폭에 비례(정규화형 conformal) + 적응형 보정(ACI, η 0.02) | 개발 포함률 75~85%를 지키는 방법 중 폭이 좁은 것 |
| **급락 경보 21시** | 로지스틱 **40%** · LightGBM 분류 **40%** · 가격신호 **20%** | 개발 구간 「재현율 80%일 때 헛경보 수」 최소 (0.1 단위 격자) |
| **급락 경보 15시** | LightGBM 분류 **50%** · 가격신호(Chronos 수요예측 없는 변형) **50%** — 수요는 자체 추정치 | 〃 |
| **급등 경보 21시 (+25%)** | 가격신호 **70%** · 로지스틱 **20%** · LightGBM **10%** (+20%: 60·10·30, +30%: 90·10·0) | 〃 |
| **급등 경보 15시 (+25%)** | 가격신호 **80%** · 로지스틱 **10%** · LightGBM **10%** | 〃 |

- **가격신호**: 가격 앙상블이 예측한 한낮 최저가(급락)와 「일 최고가 ÷ 직전 28일 기준」(급등)을 변수 하나짜리 로지스틱으로 확률로 바꾼 값이다.
- **경보 단계**: 「경보」는 개발 구간에서 사례의 80%를 맞히는 확률값 이상, 「주의」는 95%를 맞히는 확률값 이상~경보 미만이다.

## 3. 실행 순서 (저장소 최상위 `student-practice`에서)

```bash
.venv/bin/pip install torch "chronos-forecasting>=2.0"          # Chronos-2 · LSTM 용
.venv/bin/python experiments/ensemble/run_chronos.py              # Chronos-2 제로샷 7개 변형 (~15분, MPS)
.venv/bin/python experiments/ensemble/run_chronos_ft.py --steps 200 --batch 16 --lr 1e-5 --tag lora   # LoRA 미세조정 (~25분)
.venv/bin/python experiments/ensemble/run_lgbm.py --variants lgb_l1 lgb_stack --refit weekly          # 매주 재학습 (수 시간)
# 후보 비교용(선택) : run_lgbm.py(매달 3종) · run_lear.py · run_lstm.py
.venv/bin/python experiments/ensemble/tune_dev.py --members lgb_stack_weekly lgb_l1_weekly chr_ft_lora   # 개발 구간만
.venv/bin/python experiments/ensemble/ensemble.py --final         # 가격 결합·80% 범위 + 시험 평가
.venv/bin/python experiments/ensemble/warnings_model.py --final   # 급락·급등 경보 (21시·15시)
.venv/bin/python experiments/ensemble/export_results.py           # CSV 내보내기
.venv/bin/python experiments/ensemble/build_dashboard.py          # 대시보드 → outputs/ensemble/dashboard.html (더블클릭으로 열기)
```

- 산출물은 `outputs/ensemble/`에 저장된다(저장소에 올리지 않음).
  - `price_predictions.csv`: 시간별 실적·예측·80% 범위·성분별 예측
  - `warnings_daily.csv`: 일별 확률·단계
  - `targets_check.csv`: 목표 대비 달성 여부
  - `price_report.json`, `warnings_report.json`
- 맥에 Homebrew `libomp`가 없으면 LightGBM이 열리지 않는다. 이 venv에서는 `lightgbm/lib/lib_lightgbm.dylib`에 torch의 `libomp.dylib` 경로를 rpath로 추가해 해결했다. 되돌리려면 `pip install --force-reinstall lightgbm`을 실행한다.

## 5. 유의 사항

- **운영 시점**: 공표경계 판정서 v1.2에 따르면 D+1 수요예측과 D+1 SMP는 같은 시각에 공표된다. 21시 단계는 부서 운영 프로그램과 같은 가정(수요예측은 있고 SMP는 아직 없음)이다. 15시 단계가 이 가정이 필요 없는 조기 판단이다.
- **Chronos-2 사전학습**: 공개 시점(2025년 10월) 이후인 2026년 시험 구간은 사전학습 자료에 들어갔을 수 없다.
- **경보 수치의 낙관 편향**: 경보 가중치와 기준을 개발 구간에서 골랐으므로, 개발 구간 경보 수치는 낙관적이다. 성능 판단은 시험 구간 수치로 한다.
